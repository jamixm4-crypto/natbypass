Конфигурация для импорта:
📖 Как импортировать конфиг
🪟
Windows — AmneziaWG клиент
1. Скачайте AmneziaWG для Windows
2. Нажмите «Добавить туннель» → «Импорт из файла»
3. Выберите скачанный файл amneziawg-mesh.conf
🤖
Android — AmneziaWG из Google Play
1. Установите AmneziaWG из Google Play или APK с GitHub
2. В приложении нажмите «+» → «Импорт из файла или архива»
3. Выберите amneziawg-mesh.conf из Загрузок
🌐
Keenetic — через веб-интерфейс
1. Войдите в веб-интерфейс роутера (my.keenetic.net)
2. Перейдите: Компоненты → добавьте WireGuard VPN
3. Интернет → Другие подключения → Добавить подключение WireGuard
4. Вставьте содержимое конфига вручную или импортируйте файл
📡
OpenWrt — через SSH
Скопируйте конфиг на роутер и запустите: 
opkg install wireguard-tools kmod-wireguard
# Скопируйте conf файл на /tmp/wg.conf
wg-quick up /tmp/wg.conf
🔒 Стандартный WireGuard конфиг
📖 Как использовать WireGuard
🪟
Windows — официальный WireGuard
1. Скачайте WireGuard для Windows
2. Нажмите «Добавить туннель» → «Импорт туннелей из файла»
3. Выберите скачанный wg-mesh.conf
🐧
Linux — через wg-quick
sudo apt install wireguard  # или: yum/pacman/opkg
sudo cp wg-mesh.conf /etc/wireguard/wg0.conf
sudo wg-quick up wg0
# Автозапуск:
sudo systemctl enable wg-quick@wg0
🤖
Android — WireGuard из Google Play
1. Установите WireGuard из Google Play
2. Нажмите «+» → «Импорт из файла или архива»
3. Выберите wg-mesh.conf
🌐
Keenetic — WireGuard VPN
Откройте my.keenetic.net → Компоненты → Добавьте WireGuard VPN →
Интернет → Другие подключения → Создать подключение WireGuard → вставьте конфиг.
📡
OpenWrt — через SSH
opkg update
opkg install kmod-wireguard wireguard-tools luci-app-wireguard
# Настройте через LuCI или wg-quick
