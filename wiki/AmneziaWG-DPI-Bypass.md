# 🛡️ Обход блокировок через AmneziaWG 2.0

Протокол **AmneziaWG 2.0** — это глубокая модификация WireGuard, разработанная специально для преодоления современных систем глубокой фильтрации пакетов (**DPI / ТСПУ**), блокирующих стандартный WireGuard по характерным сигнатурам сетевых пакетов.

В **NatBypass** встроен полнофункциональный генератор и движок AmneziaWG 2.0.

---

## 🔬 Почему стандартный WireGuard блокируется

Классический WireGuard имеет фиксированную структуру пакетов:
1. **Handshake Initiation:** Всегда строго **148 байт** и начинается с байта `0x01`.
2. **Handshake Response:** Всегда строго **92 байта** и начинается с байта `0x02`.
3. **Cookie Packet:** Всегда строго **64 байта** (`0x03`).
4. **Data Packet:** Начинается с байта `0x04`.

Любой современный DPI-фильтр (включая ТСПУ) вычисляет эти размеры и типы пакетов за миллисекунды и сбрасывает соединение.

## 🚀 Как AmneziaWG 2.0 обходит блокировки

AmneziaWG вводит 4 уровня защиты:

### 1. Рандомизация заголовков (Magic Headers: H1, H2, H3, H4)
Вместо фиксированных `0x01, 0x02, 0x03, 0x04` используются случайные 32-битные числа, уникальные для вашей сети:
* **`H1`** — заменяет заголовок *Initiation* (например, `1428571428`).
* **`H2`** — заменяет заголовок *Response* (например, `2147483647`).
* **`H3`** — заменяет заголовок *Under Load (Cookie)*.
* **`H4`** — заменяет заголовок *Transport Data*.

### 2. Мусорные пакеты (Junk Packets: Jc, Jmin, Jmax)
Перед отправкой реального рукопожатия клиент отправляет **`Jc`** мусорных UDP-пакетов случайной длины (от **`Jmin`** до **`Jmax`** байт) со случайным содержимым.
* DPI видит хаотичный поток данных неопределенного протокола и не успевает сопоставить сигнатуру.

### 3. Смещение размера заголовков (Init/Resp Padding: S1, S2)
* **`S1`** — добавляет случайное число байт к *Initiation Packet* (пакет перестает быть 148 байт).
* **`S2`** — добавляет случайное число байт к *Response Packet* (пакет перестает быть 92 байта).

## 🎛️ Готовые пресеты в панели NatBypass

В интерфейсе NatBypass (на ПК, в Web UI или на Android) вы можете выбрать пресет в 1 клик:

| Пресет | Значения параметров | Когда использовать |
|---|---|---|
| 🟢 **Стандартный WireGuard** | `Jc=0, Jmin=0, Jmax=0, S1=0, S2=0, H1=1, H2=2, H3=3, H4=4` | Для локальных сетей без цензуры (минимальный оверхед). |
| 🟡 **Обход DPI (Рекомендуется)** | `Jc=4, Jmin=40, Jmax=70, S1=48, S2=32, H1=1428571428, H2=2147483647...` | **Основной рабочий режим против ТСПУ / DPI.** |
| 🔴 **Максимальная скрытность** | Автоматическая крипто-генерация уникальных параметров | При агрессивных белых списках и жесткой фильтрации. |

## 📄 Пример конфигурационного файла AmneziaWG (.conf)

Вы можете экспортировать сгенерированный конфиг из вкладки **«AmneziaWG 2.0»** и импортировать в официальный клиент AmneziaVPN / AmneziaWG:

```ini
[Interface]
PrivateKey = aBcDeFg...=
Address = 10.200.0.1/24
ListenPort = 51820
Jc = 4
Jmin = 40
Jmax = 70
S1 = 48
S2 = 32
H1 = 1428571428
H2 = 2147483647
H3 = 857142857
H4 = 1122334455

[Peer]
PublicKey = xYz123...=
Endpoint = 203.0.113.10:51820
AllowedIPs = 10.200.0.2/32
PersistentKeepalive = 25
```
