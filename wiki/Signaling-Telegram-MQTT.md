# 📡 Каналы сигнализации: Telegram Bot & MQTT

Сигнальный канал (Signaling Channel) — это ключевой компонент NatBypass, позволяющий узлам сети **находить друг друга через интернет без выделенного сервера и белого IP**.

---

## 🔒 Безопасность сигнального канала

* **Через сигнальный канал НЕ передается пользовательский сетевой трафик.**
* Передаются только короткие зашифрованные маяки (beacons) с метаданными:
  * Временный IP-адрес и порт, полученный через STUN.
  * Открытый ключ шифрования NaCl / WireGuard.
* Маяки шифруются сквозным шифрованием (End-to-End Encryption) с помощью эллиптической кривой Curve25519 / XSalsa20-Poly1305. Ни Telegram, ни владелец MQTT-брокера не могут прочитать содержимое.

## 💬 1. Пошаговая настройка Telegram-бота (Рекомендуется)

Telegram — наиболее надежный канал, работающий стабильно в любых сетях.

```
┌──────────────┐                 ┌──────────────┐
│ NatBypass #1 │────(Маяк A)────▶│              │
│ 10.200.0.1   │                 │ Telegram Bot │
│              │◀───(Маяк B)─────│   (API)      │
└──────────────┘                 └──────────────┘
                                        ▲
┌──────────────┐                        │
│ NatBypass #2 │────────(Маяк B)────────┘
│ 10.200.0.2   │◀───────(Маяк A)────────
└──────────────┘
```

### Шаг 1. Создание бота
1. Откройте Telegram и в поиске найдите официального бота **`@BotFather`** (с синей галочкой).
2. Нажмите **Start** и отправьте команду `/newbot`.
3. Введите название для бота (например, `MyNatBypassBot`).
4. Введите юзернейм бота, заканчивающийся на `bot` (например, `my_super_mesh_123_bot`).
5. Скопируйте выданный **HTTP API Token** (формат: `7123456789:AAFn8...`).

### Шаг 2. Получение Chat ID
1. Найдите бота **`@userinfobot`** (или `@RawDataBot`) в Telegram.
2. Нажмите **Start** — бот пришлет ваш числовой идентификатор `Id` (например, `123456789`).

### Шаг 3. Ввод данных в NatBypass
1. В приложении NatBypass откройте вкладку **«⚙ Настройки» ➔ «Telegram»**.
2. Вставьте **Bot Token** и **Chat ID**.
3. Нажмите кнопку **`[🧪 Проверить Telegram]`** — статус изменится на «✅ Бот подключен».
4. Нажмите **«💾 Сохранить»**.
5. Повторите этот шаг на втором компьютере/телефоне с **теми же самыми данными бота**.

## ⚡ 2. Настройка MQTT-брокера

Для сценариев, где Telegram недоступен или требуется полная автономность:

### Публичные бесплатные брокеры:
* `tcp://broker.emqx.io:1883`
* `tcp://mqtt.eclipseprojects.io:1883`
* `ssl://broker.hivemq.com:8883`

### Настройка:
1. В поле **«MQTT Broker»** укажите адрес (например: `tcp://broker.emqx.io:1883`).
2. В поле **«MQTT Topic»** придумайте уникальный длинный топик для вашей сети (например: `natbypass/secure_alpha_9921/beacons`). Топик выполняет роль общего пароля вашей mesh-сети.
3. Нажмите **«💾 Сохранить»**.
