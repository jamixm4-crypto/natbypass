# 📡 Каналы сигнализации: Telegram Bot & MQTT

Сигнальный канал используется только в момент запуска для обмена открытыми ключами и STUN-координатами. Никакой пользовательский трафик через него не идет.

---

## 💬 1. Настройка Telegram-бота (Рекомендуется)

Telegram-бот — самый стабильный и надежный канал сигнализации, доступный бесплатно в любой точке мира.

1. Откройте приложение Telegram и найдите официального бота **`@BotFather`**.
2. Отправьте команду `/newbot` и укажите имя для бота (например, `MyMeshNetBot`).
3. Скопируйте выданный **HTTP API Token** (вида `7123456789:AAFn8...`).
4. Найдите бота **`@userinfobot`** (или `@RawDataBot`) и скопируйте числовой **`chat_id`** (например, `123456789`).
5. Вставьте Токен и Chat ID во вкладке **«Настройки»** NatBypass на всех ваших устройствах.
6. Нажмите кнопку **`[🧪 Проверить Telegram]`** — система подтвердит подключение.

---

## ⚡ 2. Настройка MQTT-брокера

Для полностью автономных сетей без привязки к Telegram:
1. Выберите публичный брокер (например, `tcp://broker.emqx.io:1883` или `tcp://mqtt.eclipseprojects.io:1883`) либо укажите свой приватный Mosquitto-сервер.
2. Придумайте уникальный топик вашей сети (например, `mysecretnet/nodes/beacons`).
3. Укажите этот топик на всех связываемых устройствах.
