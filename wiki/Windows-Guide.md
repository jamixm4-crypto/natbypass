# 🪟 Руководство по NatBypass для Windows

NatBypass для Windows поставляется в виде нативного приложения **`NatBypass.exe`** со встроенным легковесным движком WebView2, системным треем и драйвером Wintun.

---

## 🚀 Установка и Запуск

1. Скачайте актуальный релиз **`NatBypass-v1.2.4-windows-amd64.exe`** из [Релизов](https://github.com/jamixm4-crypto/natbypass/releases/latest).
2. Запустите файл от имени **Администратора** (необходимо для создания сетевого адаптера `NatBypass` 10.200.0.x).
3. Приложение откроется в нативном графическом окне с поддержкой Dark Mode.

---

## 🎛️ Настройка сигнального канала

1. Перейдите во вкладку **«⚙ Настройки»**.
2. Выберите способ сигнализации:
   * **Telegram Bot (Рекомендуется):** Введите токен бота от `@BotFather` и ваш `chat_id` от `@userinfobot`. Нажмите кнопку `[🧪 Проверить Telegram]`.
   * **MQTT:** Укажите адрес брокера (например, `tcp://broker.emqx.io:1883`) и уникальный топик вашей сети.
3. Нажмите **«💾 Сохранить»**.

---

## 🔄 Работа в системном трее
* При закрытии окна `[X]` приложение продолжает работать в фоновом режиме в системном трее у часов.
* Двойной клик по иконке в трее разворачивает окно.
* Правый клик открывает быстрое меню: открытие настроек, обновление IP и безопасный выход.

---

## 🛠️ Запуск в режиме системной службы Windows
Если вам нужен автозапуск до входа пользователя в систему:
```cmd
natbypass-cli.exe service install --config "C:\NatBypass\config.yaml"
natbypass-cli.exe service start
```
