# 🪟 Руководство по NatBypass для Windows

Для Windows доступны следующие варианты программы:
1. **`NatBypass.exe`** — основное графическое приложение: запускается сразу **в собственном отдельном окне** (без адресной строки и вкладок браузера, через WebView2 / Dedicated App Window) с интерактивной картой сети, графиками скорости, системным треем и полным управлением узлами.
2. **`NatBypass-GUI.exe`** — сверхлёгкое классическое нативное Win32-приложение (чистый Windows API, GDI/User32, без браузерных движков, потребляет всего 15–25 МБ RAM, идеально для слабых ПК и серверов).
3. **`natbypass-cli.exe`** — консольная версия для автоматизации, скриптов и фоновой службы Windows.

---

## 🚀 Установка и Запуск

1. Скачайте **[NatBypass.exe](https://github.com/jamixm4-crypto/natbypass/releases/latest/download/NatBypass.exe)** (или **[NatBypass-GUI.exe](https://github.com/jamixm4-crypto/natbypass/releases/latest/download/NatBypass-GUI.exe)**) из [Релизов](https://github.com/jamixm4-crypto/natbypass/releases/latest).
2. Запустите файл от имени **Администратора** (необходимо для создания и настройки виртуального адаптера Wintun).
3. Приложение откроется в отдельном окне, автоматически сгенерирует ключи сети и подключится к P2P-мешу.

---

## 🎛️ Настройка сигнального канала

1. **MQTT (по умолчанию):** Приложение автоматически использует защищённую сигнальную сеть через независимые брокеры с E2EE-шифрованием маяков.
2. **Telegram Bot (опционально):**
   * В разделе «Настройки» введите токен бота от `@BotFather` и ваш `chat_id` от `@userinfobot`.
   * Нажмите **«💾 Сохранить»**.

---

## 🔄 Работа в системном трее
* При закрытии окна `[X]` приложение сворачивается в системный трей у часов и продолжает удерживать P2P-туннель.
* Двойной клик по иконке в трее открывает окно.
* Правый клик открывает контекстное меню: копирование IP, диагностика и выход.

---

## 🛠️ Запуск в режиме системной службы Windows
Для работы до входа пользователя в систему:
```cmd
natbypass-cli.exe service install --config "C:\NatBypass\config.yaml"
natbypass-cli.exe service start
```
