# 🪟 Руководство по NatBypass для Windows

Для Windows доступны две версии приложения:
1. **`NatBypass-GUI.exe`** — сверхлёгкое нативное Win32-приложение без браузера и без WebView2/Electron (потребляет всего 15–25 МБ RAM, идеально для настольных ПК и Windows Server).
2. **`NatBypass.exe`** — служба с веб-панелью управления в браузере по адресу `http://localhost:8080`.

---

## 🚀 Установка и Запуск

1. Скачайте **[NatBypass-GUI.exe](https://github.com/jamixm4-crypto/natbypass/releases/latest/download/NatBypass-GUI.exe)** (или **[NatBypass.exe](https://github.com/jamixm4-crypto/natbypass/releases/latest/download/NatBypass.exe)**) из [Релизов](https://github.com/jamixm4-crypto/natbypass/releases/latest).
2. Запустите файл от имени **Администратора** (необходимо для настройки виртуального Wintun-адаптера с адресом из диапазона `10.1.2.x`).
3. Приложение автоматически сгенерирует ключи и подключится к P2P-сети через встроенный MQTT-меш.

---

## 🎛️ Настройка сигнального канала

1. **MQTT (по умолчанию):** Приложение автоматически использует защищённую сигнальную сеть через несколько независимых брокеров с E2EE-шифрованием маяков.
2. **Telegram Bot (опционально):**
   * В разделе «Настройки» введите токен бота от `@BotFather` и ваш `chat_id` от `@userinfobot`.
   * Нажмите **«💾 Сохранить»**.

---

## 🔄 Работа в системном трее
* При закрытии окна `[X]` приложение сворачивается в системный трей у часов и продолжает удерживать P2P-туннель.
* Двойной клик по иконке в трее открывает окно.
* Правый клик открывает контекстное меню: копирование IP, диагностика и выход.

---

## 🛠️ Запуск в режиме системной службы Windows
Для работы до входа пользователя в систему:
```cmd
natbypass-cli.exe service install --config "C:\NatBypass\config.yaml"
natbypass-cli.exe service start
```
