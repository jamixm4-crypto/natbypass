# Сценарии использования NatBypass (Practical Use Cases)

В этом документе описаны пошаговые сценарии решения типовых задач с помощью NatBypass: от совместных сетевых игр с минимальным пингом до доступа к домашней сети и использования своего роутера как шлюза в интернет.

---

## 🎮 Сценарий 1: Сетевые LAN-игры с друзьями с минимальным пингом (P2P без задержек)

### Проблема:
В современных играх (Minecraft, Factorio, Terraria, CS2, Civilization, Heroes III) для совместной игры по локальной сети требуется прямой IP-доступ. Сторонние утилиты (Hamachi, Radmin VPN) часто направляют трафик через перегруженные центральные серверы, что вызывает скачки пинга (200–500 мс) и обрывы связи.

### Решение с NatBypass:
NatBypass устанавливает прямое **сокет-в-сокет P2P соединение** между компьютерами игроков через интернет, обеспечивая физически минимально возможный пинг (прямой RTT провайдеров) без сторонних серверов.

### Инструкция:
1. **Игрок 1 (Хост игры)**:
   - Запускает `NatBypass-GUI.exe` на Windows (или CLI на Linux).
   - Придумывает название сети (комнату) и секретный ключ (например, `lan_gaming_room` и ключ сети).
   - В интерфейсе видит свой виртуальный IP: например, `10.1.1.2`.
   - Запускает локальный игровой сервер (порт по умолчанию, например `25565` для Minecraft).
2. **Игрок 2 (Клиент)**:
   - Запускает NatBypass и подключается к той же сети/комнате с тем же ключом (или сканирует QR-код из вкладки «Пригласить друга»).
   - Получает виртуальный IP (например, `10.1.1.3`).
   - В игре подключается по IP адресу Хоста: `10.1.1.2:25565`.
3. **Как проверить, что соединение прямое (0 задержки релея)**:
   - В WebUI (порт 8080) или окне NatBypass статус пира должен отображать `⚡ Direct P2P` (или `udp_direct`).
   - В консоли: `ping 10.1.1.2` — задержка должна соответствовать прямому пингу между вашими городами (например, 15–35 мс).

## 💾 Сценарий 2: Доступ к домашнему NAS, серверам и умному дому из любой точки мира

### Проблема:
У вас дома стоит NAS (Synology, TrueNAS, Raspberry Pi) или Home Assistant. Домашний провайдер использует «серый» IP-адрес (CGNAT) без возможности аренды белого статического IP, либо входящие порты заблокированы провайдером.

### Решение с NatBypass:
Вы поднимаете клиент NatBypass на домашнем роутере (Keenetic, OpenWrt) или самом сервере. NatBypass самостоятельно пробивает NAT наружу и держит постоянный защищённый туннель.

### Инструкция:
1. **На домашнем роутере (Keenetic / OpenWrt)**:
   - Установите NatBypass одной командой (см. [Keenetic Руководство](../wiki/Keenetic-Routers)):
     ```bash
     opkg update && opkg install curl && curl -fsSL https://raw.githubusercontent.com/jamixm4-crypto/natbypass/main/install.sh | sh
     ```
   - Задайте имя сети: например, `my_home_mesh`.
   - Роутер получит постоянный внутренний IP, например `10.1.1.1`.
2. **На телефоне или ноутбуке в поездке**:
   - Запустите приложение NatBypass на Android или Windows/macOS.
   - Подключитесь к сети `my_home_mesh`.
3. **Результат**:
   - В браузере открываете `http://10.1.1.1` (панель роутера) или `http://10.1.1.5:8123` (Home Assistant).
   - Подключаете сетевые папки SMB/NFS: `\\10.1.1.1\nas` так, будто находитесь в домашней сети Wi-Fi!

## 🌐 Сценарий 3: Свой защищённый интернет-шлюз (Exit Node) в командировках и гостях

### Проблема:
Находясь в поездке, общественном Wi-Fi кафе, отеле или другой стране, вы хотите безопасно выходить в интернет через своё домашнее подключение, обходя ограничения местного Wi-Fi и защищая трафик от перехвата в открытой сети.

### Решение с NatBypass:
Включите режим **Exit Node** на домашнем компьютере или Keenetic-роутере. Все ваши устройства смогут направить весь свой интернет-трафик через этот узел в 1 клик.

### Инструкция:
1. **На домашнем ПК или роутере (будущий Exit Node)**:
   - В WebUI (порт 8080) перейдите в раздел *«Маршрутизация и Шлюз»*.
   - Активируйте переключатель: **«Разрешить использование в качестве Exit Node»**.
2. **На мобильном клиенте или ноутбуке**:
   - В списке пиров найдите свой домашний компьютер/роутер.
   - Нажмите **«Использовать как интернет-шлюз (Exit Node)»**.
3. **Результат**:
   - Весь исходящий трафик шифруется и доставляется до домашнего роутера через P2P/AmneziaWG.
   - Внешний интернет видит ваш домашний IP-адрес.
   - Локальные фильтры чужого Wi-Fi полностью обойдены.
