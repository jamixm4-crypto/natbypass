# 📱 Единое приложение NatBypass для Android (All-in-One APK)

NatBypass для Android — это **единое автономное приложение со встроенным системным VPN-сервисом (`VpnService`) и ядром AmneziaWG / WireGuard**. 

Вам больше **не нужно** устанавливать Termux, консольные утилиты или сторонние VPN-клиенты. Всё работает в одном окне!

---

## 🌟 Возможности Android-приложения

* 🟢 **Подключение в один клик:** Большая кнопка включения/отключения VPN прямо на главном экране.
* 📷 **Мгновенная привязка по QR-коду:** Наведите камеру на QR-код в веб-панели ПК — телефон автоматически настроит сеть и подключится.
* 🛡️ **Встроенный AmneziaWG 2.0 (Обход DPI):** Встроенная защита от блокировок с переключением пресетов (*Стандартный*, *Обход DPI*, *Максимальная скрытность*).
* 🎛️ **Плитка в шторке Android (Quick Settings Tile):** Быстрое включение/отключение туннеля без открытия приложения.
* 👥 **Мониторинг сети в реальном времени:** Список доступных домашних ПК, роутеров и серверов со статусом и задержкой (Ping).
* 🔄 **Автоматическое восстановление связи:** Бесшовный переход при смене Wi-Fi на мобильный 4G/5G интернет.

## 🚀 Пошаговая установка и запуск

### Шаг 1 — Скачайте APK-файл
1. Перейдите в [Релизы GitHub](https://github.com/jamixm4-crypto/natbypass/releases/latest) и скачайте **`NatBypass.apk`**.
2. Установите APK на ваш смартфон (разрешите установку из доверенных источников).

### Шаг 2 — Мгновенная привязка к сети через QR-код
1. На вашем компьютере откройте веб-панель NatBypass (`http://localhost:8080`).
2. На вкладке **«🚀 Быстрый старт»** (Шаг 4) отобразится **QR-код**.
3. В приложении NatBypass на телефоне нажмите кнопку **«📷 Сканировать QR»** и наведите камеру на монитор ПК.
4. Приложение мгновенно импортирует параметры сети!

### Шаг 3 — Включение VPN
1. Нажмите большую зеленую кнопку **«ВКЛЮЧИТЬ VPN»**.
2. При первом запуске подтвердите стандартный системный запрос Android на создание VPN-подключения.
3. Статус сменится на **🟢 ПОДКЛЮЧЕНО (10.200.0.100)**.

✅ **Готово!** Теперь ваш телефон находится в одной защищенной локальной сети с домашним ПК (`10.200.0.1`) и роутером (`10.200.0.2`). Вы можете открывать сетевые папки (SMB), подключаться по SSH, RDP или просматривать домашние камеры.

## 🛠️ Для продвинутых пользователей: Режим CLI / Termux (Без APK)

Если вам нужен headless-режим в Termux без графического интерфейса:
```bash
# Скачивание бинарника ARM64
curl -sL https://github.com/jamixm4-crypto/natbypass/releases/latest/download/natbypass-android-arm64 -o natbypass
chmod +x natbypass
./natbypass start
```
Веб-интерфейс будет доступен в браузере по адресу `http://localhost:8080`.
