# 🚀 Быстрый старт NatBypass — 5 минут до первого P2P соединения

NatBypass позволяет двум устройствам за разными NAT/CGNAT (включая двойной NAT у мобильных операторов и домашних провайдеров) соединяться напрямую в защищенную P2P сеть.

---

## 📥 Шаг 1 — Скачайте NatBypass

Перейдите в [Релизы на GitHub](https://github.com/jamixm4-crypto/natbypass/releases/latest) и скачайте файл для вашей системы:

| Платформа | Файл | Примечание |
|---|---|---|
| **Windows x64** | `natbypass-v1.0.0-windows-amd64.exe` | Готовый исполняемый файл |
| **Linux x64** | `natbypass-v1.0.0-linux-amd64.tar.gz` | Серверы, VPS, Ubuntu/Debian |
| **Keenetic (MIPSLE)** | `natbypass-v1.0.0-linux-mipsle.tar.gz` | Keenetic Extra, City, Air, Giga |
| **Keenetic / RPi (ARM64)** | `natbypass-v1.0.0-linux-arm64.tar.gz` | Keenetic Ultra, Titan, Raspberry Pi |
| **OpenWrt (MIPS)** | `natbypass-v1.0.0-linux-mips.tar.gz` | Роутеры TP-Link, Xiaomi |
| **Android** | `natbypass-v1.0.0-android-arm64.tar.gz` | Для Termux / CLI |

---

## 🤖 Шаг 2 — Получите Telegram-бота (Рекомендуется)

Telegram-бот используется как защищенный сигнальный канал: устройства обмениваются через него своими публичными сокетами и сразу соединяются напрямую.

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте команду `/newbot` и задайте имя боту
3. Скопируйте **токен бота** (например: `7123456789:AAFlkjhsdf987...`)
4. Найдите бота **@userinfobot** и узнайте ваш **chat_id** (число, например: `123456789` или `-1001234567890`)

> 💡 **Нет Telegram?** Не проблема! NatBypass автоматически подключится к бесплатному публичному MQTT-брокеру.

---

## 💻 Шаг 3 — Запустите NatBypass на первом устройстве

### На Windows:
Просто дважды кликните по `natbypass-v1.0.0-windows-amd64.exe`.
Откроется панель управления в браузере: **http://localhost:8080**

### На Linux / Роутерах:
```bash
./natbypass start
```
Панель управления будет доступна по адресу `http://IP_ВАШЕГО_РОУТЕРА:8080`.

---

## 🧙‍♂️ Шаг 4 — Пройдите мастер быстрой настройки

При первом открытии панели управления вас встретит **Мастер настройки**:

1. **Шаг 1 (Канал):** Выберите «💬 Telegram Bot» или «⚡ MQTT Брокер».
2. **Шаг 2 (Настройка):** Введите токен бота и chat_id. Нажмите кнопку «🧪 Проверить».
3. **Шаг 3 (Имя):** Задайте понятное имя (например: `ПК-Дома` или `Роутер-Кинетик`).
4. **Шаг 4 (Готово):** Нажмите «🎉 Готово!». Вы увидите QR-код и данные для настройки второго устройства.

---

## 📱 Шаг 5 — Подключите второе устройство

1. Запустите NatBypass на втором устройстве (ноутбук на работе, телефон или удалённый роутер).
2. Введите **те же самые параметры Telegram токена и Chat ID** (или тот же MQTT топик).
3. Задайте имя (например: `Ноутбук-Работа`).
4. Через 30–60 секунд оба устройства увидят друг друга в разделе **«👥 Устройства»**!

---

## 🛡️ Шаг 6 — Включение туннеля AmneziaWG / WireGuard

1. В веб-панели перейдите на вкладку **«🛡️ AmneziaWG 2.0»** (для обхода DPI-блокировок) или **«🔒 WireGuard»**.
2. Выберите нужный пресет:
   - 🟢 **Стандартный** — обычный WireGuard
   - 🟡 **Обход DPI** — оптимизирован для обхода цензуры
   - 🔴 **Максимальная скрытность** — случайные уникальные сигнатуры
3. Нажмите **«📥 Скачать .conf»** или скопируйте файл.
4. Импортируйте файл в официальный клиент AmneziaWG / WireGuard на вашем устройстве.

---

## 🩺 Диагностика и устранение неполадок

Если устройства не видят друг друга:
1. Откройте панель управления → вкладка **«🚀 Быстрый старт»** → внизу блок **«🩺 Проверка подключения»**.
2. Нажмите **«🔄 Запустить»**:
   - ✅ **Интернет** — доступ к внешней сети
   - ✅ **Публичный IP** — ваш внешний адрес
   - ✅ **STUN** — возможность прямого соединения (Full Cone NAT)
   - ✅ **Сигнальный канал** — связь с Telegram / MQTT
   - ✅ **Устройства в сети** — количество найденных узлов

## ❓ Часто задаваемые вопросы

**В: Нужен ли белый или статический IP-адрес?**
> О: Нет! NatBypass специально создан для работы за «серым» IP, CGNAT и мобильным интернетом (4G/5G).

**В: Трафик идёт через Telegram / MQTT сервер?**
> О: Нет. Через Telegram передаются только зашифрованные (NaCl/Box) координаты для установки соединения. Сам VPN-трафик идёт **напрямую между устройствами (P2P)**.

**В: Как запустить NatBypass в фоне как службу?**
> О: 
> - **Windows:** `natbypass.exe service install && natbypass.exe service start`
> - **Linux:** `sudo natbypass install --service systemd`
> - **Keenetic:** `natbypass install --service entware`
