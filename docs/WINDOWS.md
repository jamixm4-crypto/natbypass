# 🪟 Инструкция по настройке для Windows (10 / 11 / Server)

NatBypass на Windows может работать в **3 режимах**:
1. **Графическое приложение (Desktop GUI):** Полноценное окно с мониторингом пиров, переключением каналов и логами.
2. **Фоновый режим в системном трее:** Без консольного окна, с быстрым меню у часов.
3. **Системная служба Windows Service:** Автозапуск при старте ПК до входа пользователя в систему.

---

## Вариант 1: Запуск Desktop GUI / Web UI

1. Распакуйте архив с программой в удобную папку (например, `C:\NatBypass\`).
2. Запустите **`NatBypass.exe`** (или `natbypass-windows-amd64.exe`):
   * Автоматически откроется веб-панель по адресу **`http://localhost:8080`**.
   * Если файл `config.yaml` отсутствует или не настроен, откроется **Мастер быстрой настройки (Setup Wizard)**, который поможет настроить Telegram/MQTT за 1 минуту без редактирования файлов вручную.
   * При закрытии `[X]` или сворачивании программа плавно уходит в трей возле часов.
   * Двойной клик по значку в трее возвращает окно.
   * Правый клик по значку открывает меню быстрых действий (Обновить IP, Web UI, Выход).

---

## Вариант 2: Запуск как системная служба Windows (Service)

Служба запускается автоматически вместе с Windows и не требует входа пользователя.

### Способ А: Через графический интерфейс
1. Запустите `NatBypass.exe`.
2. Перейдите на вкладку **«⚙ Управление и Служба Windows»**.
3. Нажмите кнопку **«➕ Установить службу»**, затем **«▶ Запустить»**.

### Способ Б: Через командную строку (PowerShell / CMD от Администратора)
```cmd
# 1. Установка службы
natbypass-cli.exe service install --config "C:\NatBypass\config.yaml"

# 2. Запуск службы
natbypass-cli.exe service start

# 3. Проверка статуса
natbypass-cli.exe service status

# 4. Остановка и удаление (при необходимости)
natbypass-cli.exe service stop
natbypass-cli.exe service uninstall
```

## Вариант 3: Интеграция с официальным клиентом WireGuard для Windows

1. В главном окне NatBypass (или в Web UI `http://localhost:8080`) перейдите на вкладку **«🔒 WireGuard»**.
2. Нажмите **«Сгенерировать актуальный wg-mesh.conf»** и скопируйте текст.
3. Откройте официальный клиент [WireGuard for Windows](https://www.wireguard.com/install/).
4. Нажмите **«Добавить туннель» -> «Добавить пустой туннель»**, вставьте конфигурацию и нажмите **«Сохранить»**.
5. Нажмите **«Подключить»**. Теперь все ваши устройства (компьютеры, роутеры, смартфоны) доступны по внутренним IP адресам сети `10.200.0.0/24`.
