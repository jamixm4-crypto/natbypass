# 🪟 Инструкция по настройке для Windows (10 / 11 / Server)

NatBypass для Windows включает **полноценный нативный графический клиент (Desktop GUI)** с поддержкой темной темы Windows 10/11, встроенным **AmneziaWG 2.0** для обхода блокировок DPI и интеграцией с системным треем.

---

## 🚀 Вариант 1: Нативное графическое приложение (Desktop GUI)

1. Запустите **`natbypass-gui.exe`** (или `NatBypass.exe`).
2. Откроется нативное окно программы с 6 вкладками:
   - **🚀 Обзор и Подключение:** Большая кнопка **«🟢 ПОДКЛЮЧЕНО»** / **«🔴 ОТКЛЮЧЕНО»**, список всех компьютеров и роутеров в вашей mesh-сети в реальном времени, их публичные сокеты и задержка.
   - **🛡️ AmneziaWG 2.0:** Переключение пресетов в один клик (*🟢 Стандартный WireGuard*, *🟡 Обход DPI*, *🔴 Максимальная скрытность*), редактирование параметров обфускации `H1–H4`, `Jc`, `S1/S2` и генерация случайных параметров.
   - **⚙️ Настройки сигнальных каналов:** Ввод токена Telegram бота с кнопкой мгновенного теста `[🧪 Проверить Telegram]`, настройка MQTT брокера `[🧪 Проверить MQTT]`.
   - **🩺 Диагностика:** Проверка интернет-соединения, публичного IP, STUN NAT Hole Punching и статуса каналов.
   - **📋 Журнал событий:** Лог подключений и смены IP в реальном времени.
   - **🛠️ Служба Windows:** Установка и запуск системного сервиса в один клик.
3. **Работа в трее:** При сворачивании или закрытии `[X]` программа остаётся в системном трее у часов. Двойной клик разворачивает окно, а правый клик открывает контекстное меню.

Служба запускается автоматически вместе с Windows и не требует входа пользователя.

### Способ А: Через графический интерфейс
1. Запустите `NatBypass.exe`.
2. Перейдите на вкладку **«⚙ Управление и Служба Windows»**.
3. Нажмите кнопку **«➕ Установить службу»**, затем **«▶ Запустить»**.

### Способ Б: Через командную строку (PowerShell / CMD от Администратора)
```cmd
# 1. Установка службы
natbypass-cli.exe service install --config "C:\NatBypass\config.yaml"

# 2. Запуск службы
natbypass-cli.exe service start

# 3. Проверка статуса
natbypass-cli.exe service status

# 4. Остановка и удаление (при необходимости)
natbypass-cli.exe service stop
natbypass-cli.exe service uninstall
```

## Вариант 3: Интеграция с официальным клиентом WireGuard для Windows

1. В главном окне NatBypass (или в Web UI `http://localhost:8080`) перейдите на вкладку **«🔒 WireGuard»**.
2. Нажмите **«Сгенерировать актуальный wg-mesh.conf»** и скопируйте текст.
3. Откройте официальный клиент [WireGuard for Windows](https://www.wireguard.com/install/).
4. Нажмите **«Добавить туннель» -> «Добавить пустой туннель»**, вставьте конфигурацию и нажмите **«Сохранить»**.
5. Нажмите **«Подключить»**. Теперь все ваши устройства (компьютеры, роутеры, смартфоны) доступны по внутренним IP адресам сети `10.200.0.0/24`.
